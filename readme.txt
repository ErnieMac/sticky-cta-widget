Adds a stylish floating call-to-action bar at the bottom of the screen.

== Description ==

This plugin adds a beautiful sticky CTA widget at the bottom of your website with customizable buttons. Each button can have its own text, icon, color, and link URL.

Features:
- Modern glass effect design
- Fully responsive
- Three customizable buttons
- Font Awesome icons
- Pulse animation on WhatsApp button
- Admin settings panel

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/sticky-cta-widget` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Configure the settings under Settings > Sticky CTA Widget

== Frequently Asked Questions ==

= Where can I find Font Awesome icon classes? =
You can browse available icons at https://fontawesome.com/icons

= How do I change the button links? =
Go to Settings > Sticky CTA Widget and update the URL fields for each button.
